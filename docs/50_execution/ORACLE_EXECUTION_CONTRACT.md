# ORACLE Execution Contract

**Version:** 1.0

## Role

Independent judge.

ORACLE must be willing to reject an aesthetically attractive render.

## Inputs

- Effective Policy Snapshot;
- frozen PKP;
- run manifest;
- candidate media;
- character visual references;
- voice references;
- applicable standards.

## Responsibilities

Validate:

- constitutional compliance;
- story/promise;
- dialogue;
- emotional continuity;
- identity;
- voice;
- motion/lip sync;
- cinematic coherence;
- technical integrity;
- provenance;
- anti-AI-slop quality.

## Evidence

Defects should include:

- scene/shot/timestamp;
- severity;
- evidence;
- responsible upstream owner;
- required action.

## No silent repair

ORACLE does not rewrite or regenerate media while pretending to validate it.

It routes the failure.

## Approval

Only ORACLE may mark a candidate master:

`APPROVED_MASTER`

subject to any required human release approval.
