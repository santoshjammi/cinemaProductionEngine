# PROMETHEUS Execution Contract

**Version:** 1.0

## Input

Primary input:

- frozen PKP;
- provider/runtime configuration;
- approved reference assets.

PROMETHEUS should not need to reinterpret the whole constitutional repository.

## Responsibilities

- generate/prepare visual assets;
- preserve character identity;
- synthesize approved exact dialogue;
- create required lip sync;
- generate motion;
- generate/choose approved music/SFX within PKP intent;
- mix;
- assemble;
- render;
- create run manifest;
- surface blockers.

## Creative immutability

PROMETHEUS may not:

- rewrite a line;
- add narration;
- remove a character from a scene;
- change a mechanism;
- change a relationship resolution;
- replace Mark/Sarah with a different-looking identity;
- change voice identity;
- invent a new scene.

## Technical fallback

A fallback is allowed only if PKP or production policy explicitly permits it.

Otherwise return:

```yaml
status: BLOCKED
reason: CREATIVE_DECISION_REQUIRED
```

## Output

- immutable run manifest;
- generated asset registry;
- candidate master;
- technical validation results;
- known limitations.
