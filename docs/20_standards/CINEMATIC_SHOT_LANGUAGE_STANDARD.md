# Cinematic Shot Language Standard

**Version:** 1.0  
**Initial profile:** Relationship psychology cinematic realism

## Principle

Do not make “two AI portraits talking at each other.”

The camera should express relationship state.

## Default conversation grammar

### 1. Establishing / two-shot
Use to establish:

- geography;
- proximity;
- distance;
- shared task;
- environmental pressure.

### 2. Speaker coverage
Medium or close framing when a line requires visible performance.

### 3. Listener reaction
Often more psychologically valuable than the speaking face.

Use it to show:

- misinterpretation;
- recognition;
- restraint;
- hurt;
- doubt;
- reconsideration.

### 4. Over-the-shoulder
Useful for tension, power, and relational orientation.

### 5. Inserts
Examples:

- laptop notification;
- untouched dinner;
- school calendar;
- work badge;
- phone;
- coffee;
- hands;
- half-finished chore;
- unopened letter.

An insert must carry story information or subtext.

### 6. Shared silence
A wider frame after an important line can be more powerful than immediate dialogue.

---

## Camera restraint

Default style:

- controlled;
- believable;
- motivated;
- minimal unnecessary movement.

Do not add camera motion because a video model offers it.

## Repetition control

Avoid using the same:

- frontal two-shot;
- lens distance;
- composition;
- camera movement;
- lighting setup

for every scene.

Variation must remain coherent with the visual bible.

## Shot function

Every shot should primarily:

- reveal;
- intensify;
- contrast;
- connect;
- transition;
- resolve.

If it does none, question its inclusion.
