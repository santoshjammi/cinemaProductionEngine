# Document Classification Standard

**Status:** AUTHORITATIVE STANDARD

The word **constitution** is reserved for slow-changing law.

## Classes

### Constitution
Defines non-negotiable principles and boundaries.

Examples:
- Cinema Master Constitution
- Psychology Sub-Constitution
- Mark & Sarah Series Constitution

### Ontology
Defines what concepts/content territory exist and how they relate.

Example:
- Relationship Psychology Content Ontology (RPCO)

### Canon / Bible
Defines persistent facts of a universe or character.

### Registry
Stores mutable operational facts.

Examples:
- coverage counts;
- voice IDs;
- visual reference IDs;
- continuity events.

### Standard
Defines measurable craft or production requirements.

### Contract
Defines an approved unit of work.

Example:
- Episode Contract

### Schema
Defines machine-readable fields and validation structure.

### Snapshot
A compiled immutable view of applicable rules at a point in time.

### PKP
Frozen executable production knowledge.

### Report
Validation, performance, audit, or learning output.

### Historical / Migration
Provides rationale and evidence only. No authority unless re-adopted.

---

## Rule

When creating a new document, first classify it.

If it does not need constitutional permanence, do not call it a constitution.
