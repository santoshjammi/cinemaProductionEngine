# UI Information Architecture

**Version:** 1.0

## Main navigation

### 1. Studio
Overview:
- active productions;
- blocked productions;
- recent approvals;
- rendering queue;
- release-ready masters.

### 2. Content Map
Visualize:
- niche;
- domain;
- problem families;
- sub-series;
- produced coverage;
- gaps;
- ORACLE/commercial signals.

For Psychology, this is the RPCO browser.

### 3. Universes
Example:
- Mark & Sarah

Views:
- character canon;
- visual references;
- voice references;
- family;
- timeline;
- continuity;
- approved recurring locations.

### 4. Episodes
Episode list with:
- ontology classification;
- status;
- part number;
- mechanism;
- continuity position;
- production status;
- ORACLE status;
- publish status.

### 5. GENESIS
Review:
- story thesis;
- synopsis;
- beat graph;
- screenplay;
- dialogue;
- emotional state graph;
- shot intent;
- PKP diff.

### 6. Production
PROMETHEUS:
- assets;
- generation jobs;
- retries;
- reference bindings;
- voice;
- lip-sync;
- assembly;
- render.

### 7. Quality
ORACLE:
- blocking failures;
- timestamps;
- character drift;
- dialogue/performance issues;
- technical checks;
- approval.

### 8. Distribution
- title/thumbnail;
- YouTube master;
- Short/Reel derivatives;
- social package;
- release status.

### 9. Governance
Read-only by default:
- constitutions;
- standards;
- current versions;
- change requests.

### 10. Legacy
Do not browse `unimportant_docs` by default.
Expose only via an explicit historical-research action.
